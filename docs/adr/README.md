# Architecture Decision Records

An ADR records one architecture decision: context, decision, consequences, rejected alternatives. It refines the
Technical Design MS-TDD-2026-033 without editing it. A correction the client should see goes to the document route
separately.

| ADR | Title | Status |
|---|---|---|
| [0001](0001-native-cost-of-goods-sold.md) | Product cost uses WooCommerce's native Cost of Goods Sold | Proposed |
| [0002](0002-minimum-shipment-state-record.md) | Minimum shipment state and timing record for Option B | Proposed |

Statuses: **Proposed** (direction, not permission to build), **Accepted** (merged after review, recorded in
`DECISIONS.md`), **Superseded** (links to its replacement). Copy [0000-template.md](0000-template.md) for a new
record, and take the next number.

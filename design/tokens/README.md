# Tokens

Empty on purpose. **No token value exists, neutral or branded.**

The token roles are listed in `../inventory/components.json`, layer `foundations`: typography roles, spacing,
grid, colour roles, radius, elevation, focus, motion. Neutral values are set with the low-fidelity wireframes:
greys, and one system typeface per script.

Brand values replace the neutral ones only after the client supplies the brand identity and approves the brand
direction in writing (OD-01, CR-02). Until then no client colour, typeface or logo appears here.

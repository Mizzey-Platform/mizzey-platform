ad-staff-log · default

The log as it opens: newest first, one row per recorded event, with the search box and the item count. A new screen in the list-table idiom; the added menu item is the only change to the menu.

ad-staff-log · empty

Nothing recorded yet. In practice seen only on a new installation, before the first sign-in is logged; drawn because the state list requires it.

ad-staff-log · list

A full page of the log, shown with keyboard focus on an object link, the one place a row leads somewhere.

ad-staff-log · search

A search applied: the term stays in the box and is repeated beside the title, and the count is the count of matches.

ad-staff-log · no_results

A search with no match: the same table and the native empty wording, with the term kept so it can be corrected.

ad-staff-log · delete_refused

ADM-133: an ordinary user cannot delete the log from the interface. The list has no delete control of any kind; a delete request sent to the address directly is refused by WordPress’s capability check.

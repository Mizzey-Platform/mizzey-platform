cal-05: Product detail page

IX-04 · Gallery navigation and zoom
Shows: Thumbnail strip with a main image. Zoom: hover magnifier on desktop, plus a full-screen view on press.
Alternatives: image grid (B), horizontal strip with counter (C).
IX-03 · Buy actions in reach
Shows: 2Buy area in the page flow only. The gallery is the same height as the buy area, so nothing scrolls away before the buttons.
Alternatives: sticky beside the gallery (B, C), sticky bar on mobile (B, C).
IX-08 · Information around the description tab
Shows: 3Candidate 3: a Description tab and a Specifications tab (table, PDP-13). Key features are their own block (PDP-11). Delivery, returns and authenticity sit as quiet rows under the buy actions.
The full description stays a tab on every viewport (PDP-12, fixed).
Gallery change.
Add feedback (adding, added).
OD-08 — Returns window is a variable, no number of days.
OD-13 — Authenticity statement is a region with placeholder text, no guarantee wording.
Not drawn, by scope: back-in-stock signup (PDP-23), verified-purchase badges (DQ-06, REV-07), wishlist sharing (WISH-08), photo reviews (REV-06 to REV-09).
Flow-only is the calmest and needs no addition to the native template. It works because the buy area is short; a product with long option lists would make B’s sticky column the safer choice.
Gallery strip moves to the right, the inline-start edge; thumbnails read top to bottom unchanged. Images are not mirrored. The size row reads XS to XL from the right, letters unchanged. Price, rating and dates keep Western digits and digit order (DQ-01). The quantity stepper puts minus at the inline-start (right). Arabic product names run longer, so the title wraps to two lines at the same size. Specifications labels sit at the right, values at the left.

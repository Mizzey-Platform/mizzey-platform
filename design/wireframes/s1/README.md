# First-release wireframes

The calibration set is in `calibration/<a|b|c>/`, one file per frame and language. It is reviewed, and the
owner's selection is in [../manifest.json](../manifest.json) under `selection`. **No production wireframe exists
yet.** The first-release surfaces go in one folder per review batch, `<batch id>/<surface id>.<en|ar>.html`.

The format is in [../README.md](../README.md), and the workflow in [../workflow.md](../workflow.md).

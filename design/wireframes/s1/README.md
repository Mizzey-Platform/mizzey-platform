# First-release wireframes

The calibration set is in `calibration/<a|b|c>/`, one file per frame and language. It is reviewed, and the
owner's selection is in [../manifest.json](../manifest.json) under `selection`. **Batch-01, in
`batch-01/`, is reviewed and closed. Batch-02, in `batch-02/`, is reviewed and closed. Batch-03, in `batch-03/`, is reviewed and closed. Batch-04, in `batch-04/`, is reviewed and closed. Batch-05, in `batch-05/`, is reviewed and closed. Batch-06, in `batch-06/`, is reviewed and closed. Batch-07, in `batch-07/`, is reviewed and closed.** The first-release surfaces go in one folder per review batch,
`<batch id>/<surface id>.<en|ar>.html`.

The format is in [../README.md](../README.md), and the workflow in [../workflow.md](../workflow.md).

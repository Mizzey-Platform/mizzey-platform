Default

The address book (ACCT-04): the saved addresses as cards (cm-address-card, address-book variant), the default first and tagged, each with Edit and Delete, and one action to add an address.

Empty

No saved address yet: one line and one action.

List

Several addresses: the default first, the others in the order they were added.

Default marked

Which address is the default, and how it is set: the tag on the card, and the checkbox in the form.

Add or edit form

The batch-05 address fields and rules: phone required, landmark optional pending confirmation, governorate, city and district as dependent selects.

Validation

On Save with fields missing: the error summary first, then each field’s message (fb-inline-validation), in both languages (US-07-01).

Delete confirm

Delete asks once, in a dialog (fb-modal), and says that past orders keep their address (US-10-04). Deleting the default must say what becomes the default, or that none remains: both drawn as notes, neither decided.

Saved

Back on the book after Save: one success notice above the list, and the saved card in place.

Default

The desktop sidebar beside the grid (IX-01, locked), at the inline start. Groups are disclosure buttons; the first five are open on arrival, the rest closed. On mobile the same groups live in the drawer (PLP-22).

None applied

Nothing chosen: no “Clear all”, no active filters above the grid, and the full count.

Applied

Four filters across four groups. Every change applies at once on desktop, keeps the chosen sort (US-03-04) and is announced politely as a new count.

An option that would return nothing

With the current choices, some options would produce no products. They stay in place, disabled, so the list does not jump.

Long content: many values in one filter

Sixteen colours with long names, and long category names. Arabic is judged at 360.

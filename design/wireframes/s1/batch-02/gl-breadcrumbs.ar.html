Long content: a deep category path

Six levels with a long current name. The rule: on mobile, Home, a “…” control, the parent and the current page; the parent and the current page each truncate with an ellipsis and the row never wraps. Pressing “…” shows the full path in place, wrapping onto as many lines as it needs. On desktop the full path is shown while it fits on one line; past that, the same collapse applies.

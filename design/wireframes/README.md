# Wireframes

Empty on purpose. **No wireframe exists.**

Low-fidelity structural wireframes are drawn here, one surface at a time, in English left to right and Arabic
right to left, mobile first. The first is drawn only when the owner approves the start of the wireframe pass
(D-14). Second-release surfaces are not in that first pass: they get their own low-fidelity pass afterwards,
once the structural component and interaction system is stable, and before PRE-03b is approved (DQ-04).

A wireframe starts from the working baseline of each interaction option that bears on its surface, recommends a
pattern and shows the alternatives where the choice changes the experience. Drawing a pattern does not lock it.
`../direction.md` is the quality it is composed for, in neutral terms.

They are design artefacts. They are not built in `mizzey-theme/`, they are not approved interface design, and
they are not a client deliverable: the contracted artefact is the working HTML and CSS screens of PRE-03b,
produced after the brand identity is approved.

The file format is not decided. `PATH_POLICY` accepts only markdown and JSON under `design/` today, and the
format is added to it in an `internal:governance` PR when it is approved.
